## Quem sou

Desenvolvedor **full stack** com foco em construir software que resolve problema de negócio de
verdade. Meu diferencial é enxergar um processo manual, entender o que dói e entregar um sistema
que economiza tempo e dinheiro — do modelo de dados à interface, passando pelo deploy.

Trabalho ponta a ponta: escrevo a API, modelo o banco, construo o front e coloco no ar com
Docker/Kubernetes na AWS, com pipeline de CI/CD. Concluindo **Análise e Desenvolvimento de
Sistemas (ADS)** e sempre estudando arquitetura e boas práticas.

> Também atuo como Product Owner e líder técnico quando o projeto pede — mas o que me move é código.

---

## O que eu entrego

```text
◆ APIs em .NET bem arquitetadas, testáveis e prontas para escalar
◆ Front-ends em Vue que conversam de verdade com o back
◆ Modelagem e otimização em PostgreSQL e SQL Server
◆ Automações em Python/Node que eliminam trabalho repetitivo
◆ Deploy conteinerizado (Docker/K8s) na AWS com CI/CD
```
